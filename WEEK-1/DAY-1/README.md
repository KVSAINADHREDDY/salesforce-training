# Salesforce Fundamentals - Week 1, Day 1

## 1. What Problem Does Salesforce Solve?

Salesforce solves the problem of managing customer relationships and business processes efficiently. It helps companies:
- Store customer data
- Track sales
- Automate workflows
- Manage customer support
- Improve communication between teams

All through a cloud-based platform.

---

## 2. What is CRM?

**CRM** stands for **Customer Relationship Management**.

It is a technology or system used by businesses to:
- Manage interactions with customers
- Store customer information
- Track sales
- Provide support
- Improve customer satisfaction

---

## 3. What is an Object in Salesforce?

An **Object** in Salesforce is a database table used to store data related to a specific business activity or entity.

### Example Objects:

| Object | Purpose |
|--------|---------|
| **Account** | Stores information about companies or customers |
| **Contact** | Stores details about individual contacts |
| **Opportunity** | Tracks sales opportunities |
| **Lead** | Manages potential customers |

---

## 4. Difference Between Salesforce Admin and Developer

| Aspect | Salesforce Admin | Salesforce Developer |
|--------|-----------------|----------------------|
| **Responsibility** | Manages and configures Salesforce applications | Builds custom applications and functionalities |
| **Tasks** | Creates users, reports, dashboards, and workflows | Writes Apex code, Lightning components, and integrations |
| **Approach** | Works mostly with clicks and configuration | Works with coding and development tools |
| **Focus** | System management | Customization and automation |

---

## 5. Real-World Application: Hospital Management System

A **Hospital Management System** can be built using Salesforce.

### Capabilities:
- **Patient Records Management** – Store and manage comprehensive patient information
- **Doctor Appointments** – Schedule and track appointments
- **Billing** – Handle billing and payments
- **Emergency Support** – Quick access to emergency services and patient data
- **Team Communication** – Enable communication between patients and hospital staff

All in a **centralized cloud platform** for better efficiency and accessibility.
